## サイズ制限の解除
1. VSCodeの設定画面を開きます（Ctrl + , またはメニューの歯車アイコン）。
1. 右上のドキュメントアイコン（JSONファイルを開く）をクリックして settings.json を開きます。
1. 以下のコードを追加します。

```
"plantuml.commandArgs": [
    "-DPLANTUML_LIMIT_SIZE=8192"
]
```
## PNG画像の解像度（DPI）を上げる
PNGで書き出す際、デフォルトの解像度（96 DPI）だと文字がぼやけてしまうことがあります。コードの先頭付近に以下の記述を追加することで、高解像度で出力できます。<br>

```
@startuml
' 解像度を300 DPIに設定（好みに合わせて300〜600等に調整）
skinparam dpi 300

A -> B: メッセージ
@enduml
```
